# 好运地图：内容表已回写 HTML（V0.6 内容版）

本版本将用户提供的《好运地图_19个地点内容核验表_V1.xlsx》中的 19 个地点内容写入 `js/data.js`，并在地点详情页展示预约与票务核验记录。

- 保留原有 Hero、背景图、CSS、配色、字体和页面结构。
- 上海文庙保留并标记「开放状态待确认」。
- 杭州月老祠使用黄龙洞圆缘民俗园内现址名称与地址。
- 六条模拟帖子不再进入公开精选列表。
- 预约平台没有可核实链接的，明确显示未取得链接，不生成虚构预约按钮。
- 地点来源、核验状态、核验日期及备注保存在每条地点数据中。

注意：该版本是按用户提供的核验表回写，不代表表格中的所有内容已由独立实地或实时平台验证。动态票价、库存和临时公告应以来源页面当日信息为准。
