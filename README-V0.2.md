# 好运地图 V0.2（保留原 UI）

本版基于上传的原始文件增量修改。**未修改 css/style.css、背景图片、首页、发现页及精选页的布局。**

## 更新
- 地点详情「简介」末尾增加收藏按钮，使用浏览器 localStorage 保存；同一浏览器可再次进入地点取消收藏。
- 地点详情原有「开放资讯」模块增加官方公告区域。未有审核数据时明确显示「待核实」，不会推断正在开放。
- `js/notices.js` 是已人工审核公告的数据入口，默认空数组。只展示 `approved: true`、具有 HTTPS 来源链接、发布日期、核验日期的公告。
- 没有自动抓取、后台审核或真实开放状态查询；后续需独立实现，不能把候选采集结果直接发布。

## 测试
1. 打开 `index.html`，选择城市、愿望，进入任一地点。
2. 点击「☆ 收藏地点」，刷新页面，确认变成「★ 已收藏」，再次点击确认取消。
3. 确认开放资讯显示「最新官方开放状态：待核实」。
4. 测试原有导航按钮及其它页面链接。
5. 如果使用浏览器直接打开本地 HTML，收藏可能因浏览器存储策略受限；可用 `python3 -m http.server 8000` 启动本地静态服务器后访问 `http://localhost:8000`。

## 重要
原有地点资料和帖子仍为模拟数据。公告与用户帖子审核、真实黄历、收藏列表页均未完成。
