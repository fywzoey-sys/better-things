# 好运地图 V0.5 — 用户端信息可靠性迭代

## UI 保持不变
- 没有修改 `css/style.css`、Hero、背景、字体、配色、卡片布局或导航。
- 仅在原有黄历卡片中增加一个**默认隐藏**的初一/十五民俗提醒行。

## 新增/完善
1. `js/calendar.js`：以 Asia/Shanghai 时区计算公历和农历；农历初一、十五自动显示民俗日期提醒。它**不是**寺庙活动通知。
2. `BT.HOLIDAY_NOTICES`：为未来经官方来源核实的节假日安排预留数据字段，不伪造节假日调休。
3. `BT.getPublishableNotices`：只有人工批准、带 HTTPS 来源、且核验时间不超过 30 天的公告才能进入地点详情。过期公告不被当作当前开放状态。
4. 黄历宜忌仍明确标注**未接入**，因为尚无经确认授权的来源。
5. 原有天气 API、收藏、导航、每周精选审核规则保留。

## 数据安全与使用
- 这是静态前端，没有管理员登录或自动抓取。
- 请勿将私人 API Key 写入网页 JavaScript。
- 所有地点数据仍是演示数据，不能直接作为实地出行依据。

## 测试
- 启动本地 HTTP 服务：在项目文件夹运行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`。
- 切换城市查看天气（需联网）；查看黄历日期；打开地点详情检查公告待核实提示；收藏并刷新页面。
- 真实黄历宜忌、法定节假日来源、自动公告发现需要另行确认数据来源/授权后接入。
