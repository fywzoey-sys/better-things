# 好运地图 V0.4 — 多功能快速迭代

保持 Hero、现有 CSS、页面结构、配色和背景图不变。

## 已完成
- 首页选城市后自动读取 Open-Meteo 实时天气、温度、风速、当日降雨概率和最高最低温；15 分钟内存缓存；请求失败显示明确状态，不伪造天气。
- 无定位权限、无 API Key；使用三城市市中心近似坐标。Open-Meteo 免费接口有非商业许可等限制，商用前核对条款。
- 首页显示北京时间及浏览器内置农历日期；宜忌继续显示待接入，不伪造民俗数据。
- 本周精选仅显示 7 天内、approved=true 且有 https 来源链接的真实审核帖子。原模拟帖子仍保留在 data.js 供开发参考，但不会公开展示。
- 增加公告核验时效判断函数 noticeNeedsReview，供后续审核后台使用。

## 预览
解压后在项目目录运行 `python3 -m http.server 8000`，浏览器打开 http://localhost:8000。天气需联网。
