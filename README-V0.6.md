# 好运地图 V0.6 — 官方农历定时更新 + 本地内容审核

## UI 不变
用户端 CSS、Hero、字体、背景、卡片样式均未修改；只增加数据加载逻辑。

## 每日农历
- `scripts/update-lunar.mjs` 每次向香港天文台公历与农历对照官方 API 请求当天农历，校验结果后写入 `data/lunar-today.json`。
- `.github/workflows/daily-lunar.yml` 北京时间每天 06:17 自动运行，也可以 GitHub Actions 手动运行。工作流需要仓库允许 Actions 写入内容。
- GitHub Actions 定时任务可能延迟；只有日期匹配当天的 JSON 才会展示。若失败，前端沿用浏览器本地农历计算。
- **未自动采集「宜忌」**：香港天文台只提供历法转换，不提供宜忌；尚未确认其他黄历网站的自动抓取与再发布许可，故不伪造或无授权抓取。

## 本地审核工具（不是在线管理后台）
1. 在本地运行 `python3 -m http.server 8000`。
2. 打开 `http://localhost:8000/admin-local.html`；可导入 `data/reviewed-content.json`，添加公告/帖子、勾选人工批准，导出新的 `reviewed-content.json`。
3. 用导出文件替换 `data/reviewed-content.json`，提交 GitHub 并部署。**不要将 admin-local.html 发布到线上**，因为它没有登录和权限控制。
4. 只有 `approved: true` 且有 HTTPS 来源的记录会进入前端；公告还需核验日期在 30 天内，帖子还需发布时间在 7 天内。
5. 没有自动抓取寺庙公告或小红书笔记。没有真正安全的在线管理员权限，也没有后台数据库。

## 重要
- 当前 19 个地点仍为模拟数据；必须逐一核验后才能对外宣称真实开放情况。
- GitHub Actions 的提交可能触发 Vercel 部署（视你的仓库与部署配置）。
- 如部署为公开网站，请从发布文件中移除 `admin-local.html` 与 `js/admin-local.js`。
- 本地打开 file:// 可能无法读取 JSON；请通过本地 HTTP 服务访问。
